# El Alicanto y la vicuñita

Guía de ensayo para la evaluación sumativa de la semana 6 de MUSV0059: una experiencia artístico-musical para Nivel Transición inspirada en la Zona Norte de Chile.

Incluye la lista de materiales y las placas del video, el cuento sonoro del Alicanto con sus efectos, el ritmo del huayno («VI-cu-ña») con audio, la canción «La vicuñita» con melodía guía y letra sincronizada, la coreografía en hilera, la escaleta de 7:40 con teleprompter, las pistas para grabar por capas y la revisión con la pauta.

Página publicada con GitHub Pages: abre `index.html`. Los sonidos son sintetizados en el navegador y sirven solo para ensayar.
